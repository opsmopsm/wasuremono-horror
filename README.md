# 忘れ物（Wasuremono）— PS1風 夜の校舎ホラーゲーム

Three.js と Web Audio API で構築した、PS1（初代プレイステーション）風のローポリ・ショートホラーゲームです。

## あらすじ
吹奏楽部の片付けで遅くなった夜。田舎の古い高校からの帰り道、友達の由香には先に帰ってもらい、主人公・美咲は一人で教室へ忘れ物（家の鍵と明日の楽譜が入ったポーチ）を取りに戻る。
しかし教室にポーチはなく、別館2Fの音楽室へ向かった瞬間から、**赤いコートと赤い帽子を被った「形がいびつな女」**が夜の校舎を徘徊し始める――。

## 主な機能
- **3階建てコの字本館 ＋ 中庭 ＋ 2Fガラス張り渡り廊下 ＋ 別館2階建て**の3D校舎マップ
- **PS1風ビジュアル＆サウンド**：低解像度ピクセル描画（`P`キーで切替可能）、`NearestFilter` 粗めプロシージャルテクスチャ、スキャンライン、明滅蛍光灯、接近するほど速くなるメトロノーム音・心拍音
- **ロッカー隠れシステム（隙間スリット視界）**：校舎内13台のロッカーに隠れて、通気スリットの隙間から廊下を覗き込める（目の前で見られながら隠れるとこじ開けられる）
- **フェイクびっくりNPC**：見回り中の警備員・残業中の顧問の先生（会話セリフあり）
- **所持品インベントリHUD ＆ 4種類のマルチエンディング（達成図鑑つき）**
  - `BAD END ①` 新しい忘れ物
  - `BAD END ②` 明日でいいか（隠しエンド）
  - `NORMAL END` 逃げ切った夜
  - `TRUE END` もう、忘れない

## 起動方法
Node.js がインストールされていればすぐ遊べます。

```bash
npm install
node server.js
```

起動後、ブラウザで `http://localhost:3456` を開いてください（Windows なら `start.bat` のダブルクリックでも起動できます）。

## 操作方法
| キー | 操作 |
| :--- | :--- |
| `WASD` / `マウス` | 移動 / 視点操作（ロッカー内では隙間から左右を覗く） |
| `Shift` | 走る（スタミナ消費） |
| `C` / `左Ctrl` | しゃがむ（見つかりにくくなる） |
| `E` | ドア開閉・ロッカーに隠れる／出る・NPCと話す・調べる・アイテムを取る |
| `F` | 懐中電灯 ON/OFF |
| `M` / `Tab` | 校舎見取り図（現在地・隠れロッカー・未回収アイテム表示） |
| `P` | PS1画質 ⇔ クリア画質の切り替え |
